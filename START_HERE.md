## 📋 Quick Reference

### Commands
```bash
npm run compile       # Build extension
npm test             # Run tests (31/31 ✅)
npm run check-types  # TypeScript validation
npm run package      # Create VSIX
```

### VS Code Commands
```
@wiki ingest         # Add documents from /raw
@wiki search [topic] # Search wiki pages
@wiki lint          # Check wiki quality
@wiki indexRebuild  # Rebuild index
```

### Keyboard Shortcuts
- `Cmd+Shift+P` - Open Command Palette
- `Cmd+K Cmd+L` - Create Markdown link
- `Cmd+/` - Toggle comment
